# Free Render + existing Supabase

Current target: Render Free, no disk, no paid plan. `render.yaml` defines the free Docker service. Supabase PostgreSQL keeps the existing accounts and business data. Private files are persisted to the `talentsouk-private` bucket using `UPLOAD_STORAGE=supabase`; `/data/uploads` is only a disposable local cache. The bucket must remain private, with no anonymous policies. SUPABASE_STORAGE_KEY is a server-only service role key: never put it in frontend code or Git. Existing authenticated owner-scoped Flask routes serve downloads.

Set SECRET_KEY to the existing local value (encrypted Gmail credentials depend on it), DATABASE_BACKEND=postgres, DATABASE_URL and DATABASE_SCHEMA. Add SUPABASE_URL, SUPABASE_STORAGE_BUCKET and SUPABASE_STORAGE_KEY privately in Render. Migrate existing local uploads before sharing the site. Do not delete the local backup after migration. Eight existing files were migrated and checksum-verified during preparation; cold-cache recovery also passed.

Render Free blocks SMTP ports. Set EMAIL_PROVIDER=brevo, BREVO_API_KEY, BREVO_SENDER_EMAIL (verified sender) and SMTP_FROM_NAME=TalentSouk for email verification, reset and notifications over HTTPS. Without an approved email account, registration is not launch-ready. No real email is sent by unit tests. RENDER_EXTERNAL_URL supplies public mail links unless APP_BASE_URL overrides it. Gmail OAuth needs its own public redirect configuration if enabled.

Keep RADAR_AUTO_SYNC=0 on the initial free service. Free services sleep on idle, so background mail/reminder delivery runs only while the process is awake; do not promise continuous delivery. Supabase Free has storage/egress quotas and idle project pausing. No paid upgrade should be enabled automatically.

Build uses the included Dockerfile, Gunicorn with one process/four threads, the provider PORT, and /api/health. Docker is not running locally: the actual Render build and public HTTPS smoke checks still need verification.
